# Confounder-Controlled Partial Pearson Correlation (`pearson_partial_corr_d56`)

> Category: **Multivariate Inference** | Language: **R (Base 4.x)**

## Overview

Computes first-order partial correlation r_{XY|Z} controlling linearly for a continuous confounder Z without matrix inversion.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Partial correlation remains bounded inside [-1, 1] cleanly.
