# CART Classification Gini Impurity & Split Gain Evaluator (`gini_impurity_split_d57`)

> Category: **Tree Splitting Criteria** | Language: **R (Base 4.x)**

## Overview

Computes exact binary Gini impurity 1 - sum(p_k^2) and weighted child purity reduction gain for CART classification trees.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(K)` |

## Mathematical & Safety Invariants

- Pure homogeneous leaf yields zero Gini impurity while gain is strictly non-negative.
