# Gaussian-Scaled Median Absolute Deviation (MAD) Estimator (`zscore_mad_robust_d58`)

> Category: **Robust Statistics** | Language: **R (Base 4.x)**

## Overview

Computes robust scale dispersion via 1.4826 * median(|x - median(x)|) resistant to extreme single-point corruptions cleanly.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Constant location shifts leave MAD invariant and rescaling by C multiplies MAD by |C|.
