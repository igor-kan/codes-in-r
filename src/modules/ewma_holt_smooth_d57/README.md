# Causal Exponentially Weighted Moving Average Filter (`ewma_holt_smooth_d57`)

> Category: **Time-Series Filtering** | Language: **R (Base 4.x)**

## Overview

Applies causal single-exponential smoothing s_t = alpha * x_t + (1 - alpha) * s_{t-1} while keeping level bounded inside input extrema.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Constant input sequences remain invariant and outputs stay inside [min(x), max(x)].
