# Rank-Exact Area Under ROC Curve Evaluator (`auc_roc_trapezoid_d59`)

> Category: **Classifier Evaluation** | Language: **R (Base 4.x)**

## Overview

Evaluates exact binary classification Area Under ROC Curve via average-rank Mann-Whitney U normalization.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Perfect score separation produces AUC == 1.0 while inverted labels produce AUC == 0.0.
