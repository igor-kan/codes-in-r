# Classical One-Way ANOVA Between/Within F-Statistic (`anova_oneway_f_d59`)

> Category: **Experimental Design** | Language: **R (Base 4.x)**

## Overview

Partitions total sum of squares into between-group and residual within-group variance cleanly yielding ANOVA F-ratio.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(K)` |

## Mathematical & Safety Invariants

- Result agrees identically with base stats::aov / oneway.test(var.equal=TRUE).
