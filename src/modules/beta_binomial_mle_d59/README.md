# Method-of-Moments Beta Distribution Parameter Fit (`beta_binomial_mle_d59`)

> Category: **Parametric Estimation** | Language: **R (Base 4.x)**

## Overview

Estimates Beta(alpha, beta) shape hyperparameters directly from sample mean and sample variance over open unit-interval data.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N)` |
| **Space Complexity** | `O(1)` |

## Mathematical & Safety Invariants

- Reconstructed mean alpha/(alpha + beta) reproduces empirical sample mean cleanly.
