# Kaplan-Meier Nonparametric Right-Censored Survival Curve (`kaplan_meier_surv_d56`)

> Category: **Survival Analysis** | Language: **R (Base 4.x)**

## Overview

Computes exact product-limit survival probabilities S(t) = prod (1 - d_i / n_i) over sorted event times with right-censored risk sets.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Survival probabilities stay bounded monotonically non-increasing within [0, 1].
