# Tie-Aware Spearman Rank Monotonicity Correlation (`spearman_rank_corr_d56`)

> Category: **Rank Statistics** | Language: **R (Base 4.x)**

## Overview

Transforms observations into fractional average ranks and computes exact Pearson correlation across ranks for nonparametric monotonic trend tests.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Strictly monotonic transformations yield Spearman rho == +/-1.0.
