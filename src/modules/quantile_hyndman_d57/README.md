# Hyndman-Fan Type-7 Continuous Empirical Quantile (`quantile_hyndman_d57`)

> Category: **Order Statistics** | Language: **R (Base 4.x)**

## Overview

Evaluates Hyndman-Fan type-7 interpolated sample quantiles over empirical vectors identically to R default quantile() semantics.

## Complexity Guarantees

| Metric | Asymptotic Bound |
| :--- | :--- |
| **Time Complexity** | `O(N log N)` |
| **Space Complexity** | `O(N)` |

## Mathematical & Safety Invariants

- Type-7 quantile agrees identically with stats::quantile(x, p, type = 7).
